# Portal Acadêmico DevOps

Projeto-base para atividade prática de colaboração com Git e GitHub, desenvolvido colaborativamente com foco em boas práticas de desenvolvimento e integração contínua.

## Objetivo

O **Portal Acadêmico DevOps** é um projeto educacional que visa:

- **Aprender colaboração com Git e GitHub**: Praticar fluxos de trabalho em repositórios compartilhados
- **Evoluir um portal web**: Melhorar continuamente uma página web através de contribuições colaborativas
- **Implementar boas práticas**: Aplicar padrões de desenvolvimento em HTML, CSS e JavaScript
- **Demonstrar DevOps**: Integração contínua com GitHub Pages para publicação automática
- **Integração em equipe**: Trabalho coordenado entre diferentes papéis (desenvolvimento, revisão, documentação)

## Tecnologias

### Frontend
- **HTML5**: Estrutura semântica do portal web
- **CSS3**: Estilização e design responsivo (43.8% do repositório)
- **JavaScript (ES6+)**: Interatividade e funcionalidades dinâmicas (13.3% do repositório)

### DevOps & Deployment
- **GitHub Pages**: Hospedagem estática e deployment automático
- **Git**: Controle de versão e colaboração
- **GitHub**: Gerenciamento de repositório e CI/CD
